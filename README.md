# Quality Defect & Root Cause Analysis Platform using Six Sigma Yellow Belt

## Overview

The **Quality Defect & Root Cause Analysis Platform** is a full-stack quality management application developed around **Six Sigma Yellow Belt** principles.

The platform extends basic process awareness into structured defect analysis and root-cause investigation. It enables users to monitor process quality, record defects, calculate defect rates, classify severity, estimate business impact, document suspected causes, capture supporting evidence, and assess cause likelihood.

The project follows a practical quality-improvement workflow:

Identify
   ↓
Measure
   ↓
Analyze
   ↓
Investigate Causes
   ↓
Prioritize
   ↓
Improve
